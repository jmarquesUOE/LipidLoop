# Tables taken from LipiDex

`FattyAcids.csv` (fatty-acid definitions used for spectral purity) and `peak_finder/Possible_Adducts.csv`
(the adduct table used by the peak finder) are copied unchanged from LipiDex 1.1
(Hutchins, Russell and Coon, *Cell Syst.* 2018, 6, 621; https://github.com/coongroup/LipiDex), MIT licence.
LipidLoop reads both so that its identification stage scores exactly as LipiDex does. The LipiDex Java
source itself is not redistributed here; see `docs/LIPIDEX_ALGORITHM.md` for what was reproduced and how.
